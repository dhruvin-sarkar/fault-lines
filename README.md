# Fault Lines

Attack tolerance and structural robustness of the complete *Drosophila* male central nervous system connectome.

This repository measures how sensory-to-motor connectivity in the male CNS cell-type graph (`male-cns:v1.0`, Berg et al., *Cell* 2026) degrades when cell types are removed at random or by targeted attack, and tests the result against degree-preserving randomized graphs.

Work in progress.
